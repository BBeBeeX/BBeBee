# @bbebee/plugin-visualizer-ui-desktop

Desktop UI views for `@bbebee/plugin-visualizer`.

- Provides `VisualizerCanvas` for real-time spectrum and waveform rendering in the now playing page.
- Provides `VisualizerSettingsCard` for style configuration, color theme selection, and live previews in settings.
- Registers view `visualizer.canvas` and contributes to the `now-playing.visualizer` slot.
- Registers view `visualizer.settings`.
